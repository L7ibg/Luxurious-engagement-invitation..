# دعوة عقد قران — نور & عبدالقادر

موقع دعوة عربي فاخر (RTL) بتصميم سينمائي، جاهز للنشر مباشرة على GitHub Pages.

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو شغّل خادماً محلياً:

```bash
python3 -m http.server 8000
```

## النشر على GitHub Pages
1. ارفع محتويات المجلد إلى مستودع GitHub.
2. Settings → Pages → Source: `main` / `root`.
3. الموقع يعمل فوراً دون أي تعديل (كل المسارات نسبية).

## التعديل
كل المعلومات في أعلى ملف `script.js` داخل الكائن `CONFIG`:
الأسماء، التاريخ، الوقت، المكان، رابط الخرائط، رقم الواتساب، نص الدعوة، نص الفوتر، والصور.

```js
const CONFIG = {
  bride: "نور",
  groom: "عبدالقادر",
  date: { year: 2026, month: 9, day: 3, hour: 15, minute: 0 },
  whatsapp: "9647700000000", // ضع رقمك بصيغة دولية بدون +
  ...
};
```

> غيّر `whatsapp` إلى رقمك الحقيقي حتى تعمل أزرار واتساب وتأكيد الحضور.

## المحتويات
```
index.html      الهيكل الدلالي
style.css       نظام التصميم (أسود/عاجي/ذهبي، زجاجية، حركات)
script.js       الإعدادات + كل التفاعلات
assets/         الموسيقى الخلفية (music.mp3)
fonts/          خطوط Amiri و Tajawal محلياً (بدون اتصال خارجي)
icons/          الأيقونة والزخرفة
images/         صور المعرض والغلاف
```
